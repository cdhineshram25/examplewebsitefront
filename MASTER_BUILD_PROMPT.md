# CACAO — Master Build Prompt & Project Documentation

## Project Vision
A premium luxury chocolate 3D scroll-driven web experience called **CACAO** built using vanilla HTML5, CSS3, and JavaScript, powered by Lenis smooth scrolling and GSAP ScrollTrigger.

## Assets Architecture
- `chocolate-story.mp4`: Merged 14.5s hero video (V01 → V06)
- `frames/frame_0001.jpg` – `frames/frame_0290.jpg`: 20fps 960x540 extracted frames for canvas scroll-scrub
- `images/`: High-resolution source images for cocoa pod, revealed beans, roasting, transformation, mold, finished bar, pickup, and model tasting
- `videos/`: High-definition video clips for horizontal craftsmanship rail (V01 to V06)
